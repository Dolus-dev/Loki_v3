## Helpful Notes:

In the event of an error with the following code: `ERR_PACKAGE_PATH_NOT_EXPORTED`

Please make sure to edit the tsconfig.json located at the root of this project such that module resolution appears as such:

```
"moduleResolution": "bundler"
```
